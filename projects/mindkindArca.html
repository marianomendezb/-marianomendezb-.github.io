Mindkind - El Arca Nuclear

Client: Cincho Games
Work: Generative music, audio implementation
Info:

Gameplay music for Mindkind, and indie game from the argentinian developers Cincho Games.

The game uses a generative music script that randomly triggers audio samples that when combined create melodies, ambiences and soundscapes, so that the soundtrack constantly changes.

I worked in Unity to implement the audio samples and mix the stems. Also got involved in tweaking the script in and a bit of coding in C# for some audio parameters.

Play and pre-save at Minkind.ar
